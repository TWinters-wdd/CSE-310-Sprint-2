# Chess Application

A terminal-based application where a user can play a chess game against another player. The application will only allow the users to play legal moves. Castling and En Passant are included in the legal moves.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download the Visual Studio Community Edition
2. Add the Desktop Development with C++, Mobile Development with C++, Game Development with C++, and the Linux and embedded development with C++ workloads with the Visual Studio Installer.
3. Open the Project

Instructions for using the software:

1. Have the project folder open in Visual Studio Community Edition
2. Click the run without debugging button in the top of the IDE
3. Use chess notation to move the pieces on the board.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Microsoft Visual Studio 2026
* Desktop Development with C++ Workload (Visual Studio Installer)
* Mobile Development with C++ Workload (Visual Studio Installer)
* Game Development with C++ Workload (Visual Studio Installer)
* Linux and Embedded Development with C++ Workload (Visual Studio Installer)

*Note: While the program is only a terminal application, I plan on changing it to have a GUI. These workloads will help create this GUI.*
